# Frogball Final!

A quick single-player football game for phones, starring two teams of frogs. Captain the Lily Pad Legends, make a tactical choice at each moment and try to beat Bog United before the 90-second cup final ends.

## Play locally

From the repository root:

```sh
npm install
npm run dev -- frogball-final
```

The game uses tap-only controls, synthesised Web Audio sounds, responsive animation and a generated local app icon. It works offline after the production PWA has been loaded once.
