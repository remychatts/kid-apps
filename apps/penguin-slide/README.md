# Penguin Peak!

A phone-friendly side-scrolling game about a penguin racing down an icy hill. Tap, click or press Space to leap over ice blocks and rocks, then dive into the sea at the end of each of three increasingly speedy levels.

## Run locally

From the repository root:

```sh
just dev penguin-slide
```

The game uses the Web Audio API for its sound effects, so it has no external media or network dependencies. Sound begins after the first player interaction. Progress and best times stay in the current browser.
