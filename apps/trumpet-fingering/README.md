# Trumpet Fingering

Imported from `simonchatts/trumpet-fingering` at commit `e058630` (26 January 2026). The source files and assets retained their filesystem modification times during import.

Run this app from the monorepo root with `npm run dev -- trumpet-fingering`.

iPad-optimised web app for learning treble clef notes and trumpet fingering.

## Development

- `npm run dev`: run a development server
- `npm run build`: build production assets

A git commit to main does an automatic typecheck.

See [AGENTS.md](AGENTS.md) for an overview of the main modules and React components.
