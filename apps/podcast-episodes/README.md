# Podcast Episodes

Loads an RSS feed, filters its episode list and remembers useful feeds in local browser storage.

Run it from the repository root with `npm run dev -- podcast-episodes`.

The application shell works offline, but loading a feed needs a network connection and sends the supplied RSS URL to `corsproxy.io`. The source archive records `episodes.html` at 7 July 2025, 17:47:01 BST and its bundle at 17:47:08 BST.
